Stand: 12. September 2026

## Kurz

Die App sammelt keine personenbezogenen Daten, legt kein Nutzerkonto an, zeigt keine Werbung
und enthält keine Analyse- oder Tracking-Werkzeuge. Sie spricht mit dem USB-Stick an Ihrem

## Was auf Ihrem Rechner bleibt

Die einzige Einstellung der App (ob sie bei GitHub nach neuen Versionen sehen darf) liegt in
einer Datei `settings.json` in Ihrem Benutzerordner. Sie enthält einen Schalter, sonst nichts.
Wird die App entfernt, können Sie diese Datei löschen.

Beim Aufspielen der Firmware liest und schreibt die App ausschließlich auf dem angeschlossenen
USB-Stick.

## Die einzige Netzverbindung

Ist die Versionsprüfung eingeschaltet, fragt die App beim Start einmal `api.github.com` nach
der neuesten Veröffentlichung. Dabei erfährt GitHub — wie bei jedem Aufruf einer Webseite —
Ihre IP-Adresse und technische Angaben Ihres Systems. Wir erhalten davon nichts; es gibt keinen
Server von uns, mit dem die App spricht.

Diese Prüfung lässt sich abschalten: das Häkchen „Check GitHub for new versions" unten im
Fenster. Ist es aus, baut die App überhaupt keine Netzverbindung auf.

**In der Fassung aus dem Microsoft Store ist diese Prüfung ab Werk ausgeschaltet**, weil
Windows dort selbst für Aktualisierungen sorgt.

GitHubs eigene Datenschutzerklärung: https://docs.github.com/site-policy/privacy-policies/github-privacy-statement

# Privacy policy — createflow Dongle

Last updated: 12 September 2026

## In short

The app collects no personal data, creates no account, shows no advertising and contains no
analytics or tracking. It talks to the USB stick on your computer — and to nothing else.

## What stays on your computer

The app's only setting (whether it may check GitHub for new versions) lives in a
`settings.json` file in your user folder. It holds one switch and nothing else. If you remove
the app, you can delete that file.

When writing firmware, the app reads and writes only on the USB stick you plugged in.

## The one network connection

With the version check enabled, the app asks `api.github.com` once at startup for the latest
release. As with loading any web page, GitHub thereby learns your IP address and technical
details about your system. We receive none of it; there is no server of ours the app talks to.

You can switch the check off: the "Check GitHub for new versions" box at the bottom of the
window. With it off, the app makes no network connection at all.

**In the Microsoft Store build this check is off by default**, because Windows handles updates
there.

GitHub's own privacy statement: https://docs.github.com/site-policy/privacy-policies/github-privacy-statement
